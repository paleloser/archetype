# Ubiquitous language

This is the set of key terms and meanings that we use through the project (source code, documentation sites,
databases...). **Use these rigorously** either if you're creating an issue, debating about something in a thread,
opening a Pull Request, or implementing a source code change.

One `##` section per term, alphabetically, each with a short definition in plain words: what it is, what it is made of
or related to, and who creates or owns it. Link related terms. If a word must never be used for a concept, say so.
`/product-setup` helps write the first version; agents ask before inventing a term that isn't here.

## Note

A piece of text a user writes down, with a title and optional content. It is the archetype's sample resource, present
in every layer (API, domain, storage, webapp, docs) to show the conventions. Replace it, and this entry, with the
first concept of your domain.
