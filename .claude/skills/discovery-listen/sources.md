and `/discovery-listen` asks for it while it's empty (see the Learning protocol in
`.claude/README.md`).

From a Claude Code cloud session, some forums are blocked by the network policy and Reddit
rate-limits hard (429): reach those through `site:` searches instead, and note here the
date you last checked what loads. Facebook groups and LinkedIn are out of reach.

`https://www.reddit.com/r/<sub>/search.rss?q=<query>&restrict_sr=1&sort=new&t=week`
for a search within the sub.
