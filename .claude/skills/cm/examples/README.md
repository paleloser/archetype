# Approved posts

Posts the maintainer wrote or approved, one file per post (`<channel>-<topic>.md`). The
community-manager agent reads them for **voice**, not content, before drafting. Start each file
with one or two lines on what makes it a good model (the hook, the paragraph rhythm, how it
splits audiences, the closing), then the post in a `text` block, exactly as published.

`/cm` adds a post here when the maintainer approves a draft as a model.
